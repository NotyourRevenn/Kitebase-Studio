# Kitebase Studio

Independent solo digital studio focused on custom websites, AI automation, 24/7 booking chatbots, social media management, and clear monthly reporting.

## Overview

- **Swiss-Editorial Layout:** Built with crisp `1px` architectural hairlines, warm cotton paper light mode (`#f7f5f0`), deep navy-obsidian dark mode (`#0c0e14`), and a theme toggle.
- **Thermal Kite Animations:** Preserves the custom SVG kite symbols (sapphire blue, emerald green, and smooth 36-second roaming purple kite).
- **Five Core Capabilities:**
  - `01` Web Design
  - `02` AI Automation
  - `03` AI Chatbots
  - `04` Social Media Management
  - `05` Reporting & Analysis
- **Interactive System Previews:** Live mini quote calculator, chat/webhook log switcher, and monthly brief snapshot.
- **Pure Vanilla Stack:** Zero external UI frameworks, zero bloat — clean semantic HTML, CSS, and vanilla JS.

## Structure

```text
Kitebase-Studio/
├── index.html       # Semantic markup and interactive preview widgets
├── style.css        # Light/dark blueprint design system & responsive grids
├── script.js        # Theme toggle, live estimator, chat switcher, form validation
└── .gsd/            # Spec and state logs
```

## Run Locally

```bash
git clone https://github.com/NotyourRevenn/Kitebase-Studio.git
cd Kitebase-Studio
py -m http.server 8000
```
